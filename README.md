## Live site
This site introduces Listings, a college marketplace mobile app. 
Click "See how it works" to browse sample listings, try the search and category filters, and open the sample coat listing.

Open the Listings advertisement site: https://advertisement-page-for-listings.onrender.com/

## Run locally
From the repository root, run: 
python3 -m backend.serve

Open http://localhost:8001/ in your browser.
